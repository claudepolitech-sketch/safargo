# SafarGo — MVP туристического маркетплейса

SafarGo — стартовый проект сайта для рынка Таджикистана: каталог туров, фильтрация, карточки предложений, форма заявки и SQL-схема для Supabase.

## Что входит
- Адаптивная главная страница на Next.js App Router.
- Каталог туров с фильтрами по направлению, бюджету и типу отдыха.
- Демонстрационные туры (не реальные предложения; цены и доступность нужно подтвердить).
- Страница подробностей тура.
- Форма заявки с серверной валидацией, защитой от спама (honeypot и лимит запросов) и записью в таблицу `leads` Supabase. Без переменных окружения работает в демо-режиме.
- SQL-схема Supabase для профилей, агентств, туров, бронирований и модерации.
- RLS-политики как стартовая основа безопасности.
- Переменные окружения для будущего подключения Supabase.

## Стек
- Next.js + TypeScript
- CSS Modules / глобальный CSS
- Supabase (PostgreSQL + Auth) — подключается на следующем шаге

## Запуск локально
Требуется Node.js 20+.

```bash
npm install
npm run dev
```
Откройте http://localhost:3000

## Подключение базы данных
1. Создайте проект в Supabase.
2. Откройте SQL Editor и выполните `supabase/schema.sql`.
3. Скопируйте `.env.example` в `.env.local`.
4. Заполните `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
5. Реализуйте подключение SDK и серверные actions до использования реальных персональных данных или заказов.

## Важные ограничения MVP
- Поиск авиабилетов пока является демонстрационным интерфейсом; живые цены требуют договора и API поставщика.
- Заявки сохраняются только после подключения Supabase (см. выше) и не являются бронированием.
- Нет онлайн-оплаты, подтверждения наличия мест, email/SMS-уведомлений или автоматических возвратов.
- Демонстрационные туры и цены — только для макета.
- Перед production-запуском необходимо завершить авторизацию, серверную валидацию, RLS-тесты, логирование, антиспам, политику конфиденциальности и условия продажи туров.

## Предлагаемая дорожная карта
1. Подключить Supabase Auth и реальные запросы к БД.
2. Сделать кабинет агентства с созданием/редактированием туров и загрузкой фото.
3. Сделать защищённую админ-панель с модерацией.
4. Сохранять заявки в БД и отправлять уведомления.
5. Подключить платежи, возвраты и билеты через API после проверки коммерческой доступности.
6. Проверить юридические требования Таджикистана к туристической деятельности, обработке данных и онлайн-платежам.

## Деплой на Vercel
1. Загрузите проект в репозиторий GitHub.
2. На vercel.com выберите New Project и импортируйте репозиторий, настройки сборки определятся сами.
3. В Settings → Environment Variables добавьте значения из `.env.example`.
4. После выполнения `supabase/schema.sql` заявки с формы начнут сохраняться в таблицу `leads`.
